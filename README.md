# 📈 Simple Linear Regression – Salary Prediction

This repository demonstrates the implementation of **Simple Linear Regression** to predict an employee’s salary based on years of experience using Python and Machine Learning concepts.

## 🔍 Project Overview
The objective of this project is to build a regression model that analyzes the relationship between **Years of Experience** and **Salary**, and then uses that relationship to make predictions.

This project covers the complete ML workflow:
- Data loading
- Data preprocessing
- Model training
- Prediction
- Visualization

## 🗂 Dataset
The dataset used in this project is **Salary_Data.csv**, which contains:
- **YearsExperience** – Independent variable  
- **Salary** – Dependent variable  

The dataset is small, clean, and ideal for understanding regression fundamentals.

## 🛠 Technologies Used
- Python  
- NumPy  
- Pandas  
- Matplotlib  
- Scikit-learn  
- Jupyter Notebook  

## ⚙️ Steps Performed
1. Imported required libraries  
2. Loaded and explored the dataset  
3. Split data into training and testing sets  
4. Trained the Simple Linear Regression model  
5. Predicted salaries for test data  
6. Visualized regression line with actual data points  

## 📊 Model Visualization
The regression line clearly shows a positive linear relationship between experience and salary, making the model easy to interpret.
